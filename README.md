# CampusGuard Frontend

Static user interface for the CampusGuard student security assessment demo.

## Preview

Open `index.html` in a browser. In this standalone preview, student records are fictional and edits are saved in that browser's local storage.

## Modules

- Linux service assessment
- File permission assessment
- NFS security assessment
- Security reporting and recommendations

For the Node.js API-backed version, use the separate backend repository: https://github.com/Akshaya-aligeti/campusguard-backend. The backend repository includes the same frontend assets under `public/`.
